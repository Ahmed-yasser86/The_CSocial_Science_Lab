# For Recruiters

> **2 minutes.** Graph RAG Agent is a production-grade computational-social-science research platform for YouTube. It collects real recommendation and audience structure, turns it into analyzable networks, and answers research questions with an LLM intelligence agent — all from **one repository, one running service**.

## The problem it solves

Social-media platforms expose their content, but the **structure underneath** — who is recommended to whom, which channels form communities, how audiences overlap — is invisible. Researchers and product teams need a rigorous, reproducible way to:

- **Collect** it (`yt-dlp` acquisition with provenance),
- **Observe** it honestly (missing data flagged, never zeroed),
- **Analyze** it (networks, communities, echo chambers, sampling),
- **Reason** about it (a Graph-RAG agent that researches a subject / audience / ecosystem),
- **Publish** it (export to GraphML / CSV / JSON / XLSX).

This repo does all five, with every fact documented from committed code.

## The three systems in one repo

| System | What it is | Real entry point |
|---|---|---|
| **A. CSS Workbench** | YouTube collect → observe → sample → network → export. **160 API paths** (FastAPI). | `SocialScienceResearch/api/app.py:1299` `create_app()` |
| **B. Graph-RAG Agent** | LangGraph 5-node intelligence graph: identity → profile → subject / audience / ecosystem research (report router). | `RetrievalPipeline/Graph/intelligence_graph.py:506` |
| **C. Ingestion Pipeline** | Tavily crawl → chunk → embed → Qdrant with rate limiting + retries. | `Ingestion_Pipline/ingestion_service.py:162` |

## Why it is rigorous, not a demo

- **API contract is guarded by CI.** `SocialScienceResearch/tests/test_openapi_snapshot.py` fails if the live app drifts from `SocialScienceResearch/api/openapi.json` — the drift gate is described in `SocialScienceResearch/CONTRACT.md`.
- **~80 backend test modules** + 19 Playwright end-to-end suites live under `SocialScienceResearch/tests/`.
- **Validated network analysis.** The centrality battery matches `networkx` on Zachary's Karate Club to `1e-6` (`SocialScienceResearch/tests/test_centrality_benchmark.py`).
- **Never fabricates data.** Missing values are `available | missing | unsupported` (`SocialScienceResearch/domain/enums.py:137`).
