# API Reference

The platform exposes a FastAPI application mounted at the prefix
`/api/v1/social-science` (configurable via `SOCIAL_API_PREFIX`). The full
OpenAPI schema is checked in at `api/openapi.json` and regenerated by
`scripts/dump_openapi.py`; a backend test fails on drift
(`tests/test_openapi_snapshot.py`). The Next.js UI proxies the same prefix to
the backend during development (`next.config.ts`, default
`http://127.0.0.1:8000`).

## Pagination contract (ADR-0004)

All list endpoints return the same envelope:

```json
{
  "items": [...],
  "next_cursor": "…",
  "has_more": true,
  "total": 1234
}
```

- `cursor` / `page_size` query params (default `page_size=25` for explorer,
  50 elsewhere; `ge=1, le=500`).
- `total` is best-effort; large scans may return `null`.
- Invalid or stale cursors return `400` with an explanatory payload.
- The UI keeps a cursor history per page and exposes Previous/Next.

## Error envelope

Errors use a single machine-readable envelope:

```json
{ "error": { "code": "…", "message": "…", "detail": { } } }
```

## Endpoint catalogue

### Research / query (population → preview)

| Method | Path | Purpose |
|---|---|---|
| GET | `/research/variables?entity=` | Variable catalogue for an entity (drives the query builder) |
| GET | `/research/operators` | Supported operator vocabulary |
| POST | `/research/query/preview` | Funnel preview `{total, stages[{condition, matched, cumulative}]}` |
| POST | `/research/query/resolve` | Resolve a query to matching ids |

### Collection & jobs

| Method | Path | Purpose |
|---|---|---|
| POST | `/collect/channel` `/collect/video` `/collect/recommendations` | Synchronous one-off collection |
| POST | `/collect` | Spec-driven async collection job |
| GET | `/jobs` `/jobs/{id}` `/jobs/{id}/result` | Job lifecycle |
| POST | `/jobs/{id}/cancel` | Cancel a queued job |

### Provenance & corpus

| Method | Path | Purpose |
|---|---|---|
| GET | `/runs` `/runs/{id}` `/runs/{id}/errors` | Collection-run ledger, per-run errors |
| GET | `/channels` `/videos` | List entities (supports `q`, `cursor`, `page_size`) |
| GET | `/channels/{id}/history` `/videos/{id}/history` | Longitudinal observation history (oldest-first, growth %) |
| GET | `/coverage` | Corpus coverage summary |

### Explorer & provenance (ADR-0017)

| Method | Path | Purpose |
|---|---|---|
| GET | `/explore/records?entity=&q=&filters=&sort=&cursor=&page_size=` | Browse one page of rows (entity ∈ channel, video, comment, recommendation, author) |
| GET | `/explore/records/{entity}/{id}/raw` | Raw source payload |
| GET | `/explore/provenance/{entity}/{id}` | Provenance chain |

### Global search (E2, ADR-0020)

| Method | Path | Purpose |
|---|---|---|
| GET | `/search?q=&entity=&cursor=&page_size=` | Cross-entity relevance search |

### Comparison (B4, ADR-0015)

| Method | Path | Purpose |
|---|---|---|
| POST | `/comparison/videos` `/comparison/channels` `/comparison/periods` `/comparison/cohorts` `/comparison/runs` | Compare sets with `normalization=none|per_1k|z_score` |

### Samples (B5, ADR-0016)

| Method | Path | Purpose |
|---|---|---|
| POST | `/samples` | Create an immutable sample |
| GET | `/samples` `/samples/{id}` | List / fetch |
| GET | `/samples/{id}/members` | Cursor-paginated member ids |
| DELETE | `/samples/{id}` | Delete (only mutation) |
| POST | `/samples/compare` | Pairwise overlap (Jaccard) + criteria diffs |

### Datasets & projects (B7, ADR-0019)

| Method | Path | Purpose |
|---|---|---|
| CRUD | `/projects` | Persisted research projects |
| CRUD | `/datasets` | Materialized datasets |
| GET | `/datasets/{id}/members` `/datasets/{id}/quality` | Members + missing-value matrix |
| GET | `/datasets/{id}/export?format=csv|json` | Streaming export |
| GET | `/datasets/{id}/export/raw?format=json` | Raw-payload export |

### Network (B6, ADR-0018)

| Method | Path | Purpose |
|---|---|---|
| GET | `/network/metrics?run_id=&top_n=` | Density, reciprocity, clustering, components, communities, HITS |
| GET | `/network/temporal?runs=` | Per-run slice comparison |
| GET | `/network/edges` | Cursor-paginated edge listing |
| GET | `/network/channels` | Channel projection |
| GET | `/network/export?format=graphml|edgelist|gexf` | Graph export |
| GET | `/network/recommendations/summary` `/network/recommendations/{id}` | Summary + ego-network |

### Comment analytics (B3, ADR-0014)

| Method | Path | Purpose |
|---|---|---|
| GET | `/videos/{id}/comments` | Comment listing |
| GET | `/videos/{id}/comments/analytics/participation` | Participation (unique/repeat authors, Gini, concentration) |
| GET | `/videos/{id}/comments/analytics/threads` | Thread-size distribution (bounded parent-chain walk) |
| GET | `/videos/{id}/comments/analytics/velocity` | Velocity/decay, age-at-posting |
